## 二、机构介绍

### 2.1 概述

Mulan舞蹈工作室由鲍俊伟老师于2021年在加拿大渥太华创办，是一所专门针对幼儿启蒙和青少年专业培训舞蹈的学校。

工作室成立以来，依托鲍老师多年来在少儿舞蹈教育领域的丰富经验，以及带领学员参加全国最高级别舞蹈赛事的实战经验，形成了一套独具特色的教学模式和教学理念。

### 2.2 教学理念

**"学中乐、学中思、学中悟"**

在这套教学理念的指导下，学员不仅能够学会扎实的舞蹈基本功，更能体会到舞蹈带来的快乐。通过舞蹈这一艺术形式，让学员了解和感受中国五千年文化的魅力，在舞蹈艺术的世界里自由翱翔。

### 2.3 培养目标

- 培养学员的全方位舞蹈素养
- 了解多种舞蹈风格和表演模式
- 通过系统化教学，让学员亲身体验艺术与身体的完美融合
- 激发学员的学习兴趣和自信心
- 培养团队协作精神和舞台表现力

## 三、课程体系

### 3.1 课程总览

| 课程名称 | 内容定位 | 特色说明 |
|---------|---------|---------|
| **中国古典舞** | 富含华夏文化遗产的经典舞蹈 | 传承中华传统文化 |
| **中国少数民族民间舞** | 地方风情浓郁的传统舞蹈 | 多民族舞蹈风格 |
| **芭蕾舞** | 扎实的芭蕾舞基本功训练 | 芭蕾为基础，拓展多舞种 |
| **现代舞** | 善于思考的现代创作舞蹈 | 中国风风格的现代舞 |
| **爵士舞** | 时尚的爵士舞蹈表演 | 商业与表演方向 |
| **街舞** | 潮流街舞训练 | 邀请宝熊老师授课 |

### 3.2 课程特色

1. **系统化合一教学**：以芭蕾为基础，教授各个舞种的舞蹈，帮助学员建立扎实的基本功

2. **中国风特色**：特别强调中国风风格的现代舞、爵士舞，让学员深入了解舞蹈这一门类的艺术

3. **名师授课**：街舞和时装表演班邀请渥太华最受欢迎的叶子老师授课

4. **全方位培养**：不仅教授舞蹈技巧，更注重培养学员的藝術感悟力和舞台表现力

## 四、演出与赛事

### 4.1 年度学员专场秀

- **时间安排**：每年年中或年底举办
- **参与对象**：全体学员
- **活动形式**：每位学员都有机会在专属舞台上展示自己
- **评选机制**：通过相互学习，激发孩子们的学习兴趣，评选出Mulan舞蹈工作室的"**小舞王**"

### 4.2 全国"小荷风采"少儿舞蹈大赛

- **赛事级别**：国内最高级别的舞蹈赛事
- **参赛成绩**：获得优异な成绩
- **参赛意义**：为学员提供高水平的竞技和展示平台

1. **成为渥太华语舞蹈教育领域的标杆**
