# 教室出租

本文档记录当前教室出租和教室使用功能。

## 当前状态

已实现：

- 公开教室页面。
- 公开教室出租申请页面。
- 公开申请的人机验证。
- 后端必填字段校验。
- `pending` / `confirmed` 等教室预约状态。
- 后台教室首页。
- 后台待审核申请页面。
- 后台已确认预约页面。
- 后台内部教室使用页面。
- 邮件回执服务，SMTP 未配置时不影响申请保存。
- 系统设置里的同一联系方式待审核申请数量限制。
- 教室价格编辑支持中英法和图片上传。

部分实现：

- 邮件发送依赖 SMTP 配置。
- 高级审核通知流程还需要继续完善。

未实现：

- 学生账号里的个人教室申请历史。
- 教室出租付款/押金。
- 外部日历同步。

## 前台流程

1. 访客打开教室出租页面。
2. 查看已确认的教室使用时间。
3. 打开申请表。
4. 填写教室、日期时间、联系方式、用途和备注。
5. 后端创建待审核申请。
6. 如果有邮箱且 SMTP 已配置，系统尝试发送回执。
7. 管理员在后台审核。

公开用户不能直接创建已确认预约。

## 后台流程

管理员可以：

- 查看教室后台首页
- 查看待审核申请
- 查看已确认预约
- 创建内部教室使用记录
- 编辑教室使用记录
- 删除错误记录
- 设置显示到前台的已确认预约

老师账号可以访问教室工具。超级管理员还可以修改和教室申请相关的系统设置。

## 核心字段

教室预约记录主要字段：

- `room`
- `booking_type`
- `status`
- `title`
- `teacher_name`
- `applicant_name`
- `applicant_contact`
- `day_of_week`
- `start_time`
- `end_time`
- `notes`
- `translations`

## 系统设置

相关设置：

- 对外发信邮箱
- 同一联系方式最多待审核申请数量
- 中英法学校规章制度及退费规则
- 中英法教室价格内容
- 教室价格图片

## 上传

教室价格图片使用通用上传接口，保存到：

```text
UPLOADS_DIR/images/editor/YYYY/MM
```

公开 URL 由 `PUBLIC_BASE_URL` 生成：

```text
{PUBLIC_BASE_URL}/static/uploads/...
```
