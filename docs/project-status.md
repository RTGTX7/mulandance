# 项目当前状态

本文档记录当前代码已经支持什么、只做了一部分什么、以及还没有开发什么。

## 运行技术栈

- 前端：Next.js 14 App Router、React、TypeScript、Tailwind CSS。
- 后端：FastAPI、SQLAlchemy，默认使用 SQLite。
- 持久化内容：SQLite 数据库加 `data/` 目录文件。
- 语言：前台和后台支持中文、英文、法语。

## 已实现

### 前台网站

- `zh`、`en`、`fr` 多语言路由。
- 首页、新闻、活动演出、课程、价格、排课表、教师、教室出租、教室价格、隐私和条款页面。
- 公开教室出租申请表。
- 公开教室使用时间展示。

### 后台

- 后台登录。
- 两种后台角色：
  - `super_admin`：主管理员/超级管理员。
  - `admin`：老师账号/普通管理员。
- 后台菜单按功能分组：网站内容、教学管理、教室与报名、系统管理。
- 只有超级管理员可进入：
  - 账号管理
  - 系统设置
  - 报名链接
  - 价格设置
- 老师账号可进入：
  - 首页
  - 新闻文章
  - 活动演出
  - 开设课程
  - 排课表
  - 教师
  - 教室

### 内容管理

- 新闻文章支持中英法翻译分组。
- 新闻分类和标签。
- 首页按语言编辑。
- 活动演出按语言编辑。
- 课程按语言编辑。
- 排课表按语言编辑。
- 教师按语言编辑。
- 系统设置里可编辑中英法学校规章制度及退费规则。
- 价格设置支持中英法课程价格、教室价格、优惠卡片、付款方式、教室说明。
- 教室出租价格支持上传图片。

### AI

- 系统设置里可配置 OpenAI 兼容 API。
- AI API Key 只保存在后端，不暴露给前端。
- 已有 AI 翻译接口。
- 已有 URL 导入生成新闻草稿接口。
- 新闻编辑器里已有 AI 草稿助手。
- URL 导入下载的图片会保存到配置的上传目录。

### 部署

- Docker Compose 启动前端和后端。
- `HOST_DATA_DIR` 映射到容器内 `/app/data`。
- 数据库、文章 Markdown、页面 Markdown、上传图片/视频都设计为持久化保存，不随镜像重建丢失。

## 部分实现

- AI 当前主要接在新闻编辑器。其它后台模块虽然支持多语言编辑，但不是每个模块都有一键 AI 生成按钮。
- 后台语言一致性已经整理过，但少数旧页面可能仍然使用旧翻译 key。
- 教室出租有提交、查看、编辑、删除、确认流程，但高级审核通知还需要继续打磨。
