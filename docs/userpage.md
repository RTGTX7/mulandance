# 后台账号与权限

当前后台账号模型只保留两类：`super_admin` 和 `admin`。

## 角色

### 主管理员 / 超级管理员

`super_admin` 是最高权限账号，可以：

- 创建和编辑老师账号
- 启用或停用老师账号
- 重置老师账号密码
- 编辑系统设置
- 编辑 AI API 设置
- 编辑报名链接
- 编辑价格设置
- 编辑全部网站内容
- 查看和处理教室申请

只有超级管理员可以访问：

- `/admin/accounts`
- `/admin/settings`
- `/admin/registrations`
- `/admin/pricing`

### Admin

`admin` 是老师账号/普通管理员。它负责日常内容和教学相关管理，但不能修改全局系统配置。

可以访问：

- 首页
- 新闻文章
- 活动演出
- 开设课程
- 排课表
- 教师
- 教室

不能访问：

- 账号管理
- 系统设置
- 报名链接
- 价格设置

## 当前前端行为

后台导航按功能分类：

- 网站内容：首页、新闻、活动演出。
- 教学管理：课程、排课表、教师。
- 教室与报名：教室。
- 系统管理：报名链接、价格设置、系统设置、账号管理。

对于 `admin`，前端会隐藏超级管理员专属入口。如果手动输入受保护 URL，会跳回后台首页。

## 后端权限校验

隐藏按钮不等于安全。后端接口必须继续做权限校验。

当前重要规则：

- AI 接口需要 `super_admin` 或 `admin`。
- 新闻、课程、教师、排课表、活动演出、教室管理需要后台权限。
- 系统设置、报名设置、AI 设置、账号管理需要 `super_admin`。

## 账号管理

已实现：

- 查看老师账号列表
- 创建老师账号
- 修改姓名、角色、启用状态、密码
- 阻止普通管理员管理账号

当前没有做“自定义权限预设”。如果以后需要更细权限，应作为新功能开发，不要硬塞进现在的两角色模型。

## 未实现

- 大规模学生/家长账号管理。
- `super_admin` 和 `admin` 之外的角色预设。
- 每个模块单独开关权限的编辑器。
- 账号变更审计日志。

这些功能不要写成当前已经可用。
