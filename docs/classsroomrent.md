# 教室租借功能计划

## 目标

为 Mulan Dance Studio 建立一个教室租借子功能。前台网站允许外部用户提交租借申请，后台管理员负责审核、确认、显示教室使用时间、设置申请限制，并处理邮件回执。

## 用户角色

### 学生用户

- 学生不开放教室租借功能。
- 学生端不显示教室租借入口，除非后续工作室决定开放。

### 老师

- 老师可以申请或预约内部教学使用的教室时间。
- 老师预约属于内部教室使用。
- 内部预约经后台确认后，可以显示在公开教室日历中。

### 外部用户

- 外部用户可以在公开的教室租借页面提交申请表。
- 必填字段：
  - 用途 / 活动名称
  - 申请人姓名
  - 联系方式
- 选填字段：
  - 备注，例如人数、设备需求、特殊要求等
- 外部申请提交后默认进入 `pending` 待审核状态，需要管理员在后台确认。

## 前台租借页面

公开教室页面需要包含：

- 已确认的教室使用日历
- 大教室 / 小教室筛选
- 租借申请表
- 提交前必填字段验证
- 人机验证
- 提交后的成功或错误提示
- 邮件回执状态提示：
  - 回执已发送
  - 联系方式中没有邮箱
  - 邮件服务尚未配置
  - 邮件发送失败

## 前台申请表基础问题

教室租借申请表除了基础预约信息外，还应该参考活动风险评估表，询问一些必要的安全和管理问题。目标不是把表单做得很复杂，而是让学校在审核前能知道活动性质、人数、安全风险和清洁责任。

### 基础联系信息

- 申请人姓名
- 联系方式
- 邮箱
- 组织 / 团体 / 公司名称
- 申请人在活动中的角色
- 是否有第二联系人
- 第二联系人姓名
- 第二联系人电话 / 邮箱

### 活动信息

- 活动名称 / 用途
- 活动描述
- 租借教室：
  - 大教室
  - 小教室
- 使用日期 / 星期
- 开始时间
- 结束时间
- 预计参与人数
- 活动面向对象：
  - 内部学生
  - 家长
  - 外部公众
  - 私人团体
  - 其他
- 是否已经和学校工作人员沟通过该时间段

### 参与者与安全

- 是否会有未成年人参加
- 未成年人是否由家长 / 监护人 / 负责人陪同
- 是否有负责人全程在场
- 是否有急救 / CPR 负责人
- 负责人是否知道最近医院或紧急联系电话
- 是否有任何参与者需要特殊照顾或无障碍支持
- 是否有可能造成心理、社交或人身安全风险的内容

### 活动内容风险

- 是否有高强度舞蹈、翻腾、杂技或可能受伤的动作
- 是否使用道具
- 是否使用大型设备或音响
- 是否使用明火、烟雾、粉尘、喷雾或类似物品
- 是否会播放高音量音乐
- 是否会拍照或录像
- 是否邀请外部老师、嘉宾或演讲者
- 是否有售票或收费

### 食物、饮品与酒精

- 是否提供食物
- 是否提供饮品
- 是否涉及酒精
- 如果涉及酒精，是否有合法许可和专人管理
- 是否会产生垃圾或需要额外清洁

### 场地、容量与安保

- 是否理解并同意不得超过教室容量
- 是否需要控制入场人数
- 是否需要安保或额外工作人员
- 是否需要提前布置场地
- 是否需要隔夜存放物品或设备
- 是否理解学校不对未经批准存放的物品负责

### 保险、责任与协议

- 是否代表组织 / 公司租借
- 是否有责任保险
- 是否可以提供保险证明
- 是否需要和第三方供应商签合同
- 是否理解租借人需要对活动安全、参与者行为、场地损坏负责
- 是否同意遵守学校教室使用规则

### 清洁与恢复

- 活动后是否会自行清理垃圾
- 是否会把桌椅、设备、地面恢复原状
- 是否需要学校额外提供清洁
- 是否理解如果造成损坏或额外清洁，可能产生费用

### 其他说明

- 是否有其他风险或特殊情况需要学校提前知道
- 是否有其他设备需求
- 是否有其他备注

## 后台教室使用页面

后台教室使用页面需要允许管理员：

- 查看全部教室使用和租借申请
- 添加内部教室使用记录
- 查看外部租借申请
- 通过待审核申请
- 删除错误或垃圾申请
- 查看外部申请的申请人和联系方式
- 查看状态：
  - 待审核
  - 已确认
  - 已拒绝

## 后台系统设置

系统设置中需要包含教室租借相关控制项：

- 对外发信人邮箱
  - 用作网站邮件的 `From` 发信人地址
  - 后端仍然需要配置 SMTP 才能真正发出邮件
- 同一联系方式最多待审核申请次数
  - `0` 表示不限制
  - 大于 `0` 的数字表示同一个联系方式最多可以同时提交多少个待审核外部租借申请
  - 只计算 `pending` 待审核申请
  - 申请被通过或拒绝后，会释放该联系方式的申请名额

## 联系方式申请次数限制规则

外部用户提交租借申请时：

1. 去掉联系方式前后的空格。
2. 比较联系方式时忽略大小写。
3. 统计同一个联系方式下，状态为 `pending` 的外部租借申请数量。
4. 如果数量已经达到后台设置的上限，则拒绝本次提交。
5. 如果申请之后被管理员通过或拒绝，则不再占用该联系方式的申请次数。

## 邮件回执

外部租借申请提交后：

- 如果联系方式中包含邮箱，则向申请人发送表单回执。
- 回执内容需要包含申请人填写的表单内容：
  - 教室
  - 星期
  - 开始时间和结束时间
  - 用途
  - 申请人
  - 联系方式
  - 备注
  - 待审核状态
- 即使邮件发送失败，申请也应该正常保存。
