# 木兰舞蹈学校 - 开发路线图

## 项目概述

### 机构详情

**Mulan舞蹈工作室**是鲍俊伟老师2021年新注册的一所专门针对幼儿启蒙和青少年专业培训的一所舞蹈学校。

#### 教学理念

通过多年来一直从事少儿舞蹈领域的教育和带领团队参加最高级别的赛事，以及在渥太华地区少儿舞蹈教学的经验，形成了一套独具特色的教学模式和教学理念。孩子们在这套"学中乐、学中思、学中悟"的教学理念的指导下，不仅学会了扎实的舞蹈基本功，并且能体会到舞蹈带来的快乐。通过舞蹈这一艺术形式还能了解到中国五千年文化的魅力，让孩子们在舞蹈艺术的世界里快乐地翱翔。

#### 课程体系

Mulan舞蹈工作室以培养孩子们的全方位舞蹈素养，了解多种舞蹈模式为目的，在课堂上他们将学到：

- **芭蕾舞** - 扎实的芭蕾舞基本功
- **爵士舞** - 时尚的爵士舞表演
- **现代舞** - 善于思考的现代创作
- **中国少数民族民间舞** - 地方风情浓郁的传统舞蹈
- **中国古典舞** - 富含华夏文化遗产的经典舞蹈

通过系统化的教学，鲍老师让孩子们都能亲身体验感悟到艺术与身体的完美融合。

#### 特色课程

- **街舞班** - 邀请渥太华最受欢迎的叶子老师授课
- **时装表演班** - 专业的舞台表演训练

#### 演出与赛事

- **学员专场秀** - 每年年中或年底举办，每位学员都有机会在舞台上展示自己
- **"小舞王"评选** - 通过相互学习，激发孩子们的学习兴趣
- **全国"小荷风采"少儿舞蹈大赛** - 国内最高级别的舞蹈赛事，取得优异的成绩

#### 联系方式

加入我们，成为这个温暖大家庭的一员！

## 第二阶段：教务系统集成

> 目标：对接小麻雀教务系统（xiaomai5.com）的数据库

### 2.1 小麻雀系统对接

#### 分析需求

需要了解小麦教务系统的：
1. **数据库类型和结构** - MySQL? PostgreSQL? 表结构如何？
2. **数据同步方式** - API对接 or 直连数据库？
3. **需要同步的数据**：
   - [ ] 学员信息（姓名、年龄、联系方式）
   - [ ] 课程安排（时间、班级、老师）
   - [ ] 缴费记录
   - [ ] 出勤记录

#### 技术方案

```
方案A: API对接（推荐）
前端网站 ←→ 中间层API ←→ 小麻雀系统API

方案B: 数据库直连
前端网站 ←→ 后端API ←→ 小麻雀数据库（需小麻雀同意）

方案C: 数据导出导入
小麻雀导出CSV/Excel → 手动上传 → 后端导入数据库
```

### 2.2 需要对接的数据模型

| 数据表 | 用途 | 同步频率 |
|--------|------|----------|
| students | 学员信息 | 每日 |
| classes | 课程安排 | 实时 |
| payments | 缴费记录 | 每日 |
| attendance | 出勤记录 | 实时 |
