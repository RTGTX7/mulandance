## 2. Changes to Revert or Ignore

### Ignore completely:
- **All `pages/*.html` files** — These are standalone HTML files that are NOT part of the Next.js project. The Next.js frontend uses `frontend/src/app/[locale]/` for routing. These files should be deleted entirely.

### Revert:
- **`backend/app/main.py`** — Remove the static file serving mounts (`app.mount("/assets", ...)`, `app.mount("/pages", ...)`, and the `/{page:path}` catch-all route). The backend should only serve the FastAPI JSON API. The frontend (Next.js) handles all HTML/CSS/JS serving.
- **Keep `backend/app/core/security.py` changes** — The `get_current_user_id` function is actually needed by `portal.py` API routes.

### Delete:
- `recreate_index.py` — temporary recovery script
- Optionally delete the entire `pages/` directory since it serves no purpose in the Next.js architecture

## Key Principles
- **No standalone HTML files** — everything goes in `frontend/src/app/[locale]/[...]/page.tsx`
- **Reuse existing components** — Card, Button, Badge, Accordion, Breadcrumbs, etc.
- **Use `useTranslations()`** for all text, never hardcoded strings
- **Follow existing patterns** — breadcrumbs on sub-pages, section-padding wrapper, container classes
- **Add translation keys** to en.json/zh.json before creating pages that use them
